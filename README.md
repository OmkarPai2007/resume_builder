# 📄 Resume Builder Web App

A modern responsive Resume Builder Web App built using pure HTML, CSS, and JavaScript.
This web application allows users to create professional resumes with live preview, multiple resume templates, dark/light mode, image upload, and PDF export functionality.

📌 Note: This project was developed as part of my Web Development Internship at Sqrock IT Solutions. 🚀

> ⚠️ Note: All names, resume details, contact information, education, experience, skills, templates, and profile data used in this project are completely dummy/demo data created only for learning and educational purposes. Please do not share or misuse any information shown in this project.

# 🚀 Deployment

This project can be hosted using GitHub Pages.

2. Open Repository Settings
3. Go to Pages Section
4. Select Main Branch
5. Save Changes
